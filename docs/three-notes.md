The existing section components remain the content source. No project, personal detail, copy, image, font, form destination or link is generated by the cinematic renderer. The original loading SVG, bottle illustration, progress bottle, cards, circles, navigation and footer remain in the page.

## Score and rendering

- `src/lib/three-notes/score.ts`: deterministic chapter boundaries, reading holds, arrivals, circle traces, scene weights, quality budgets and light/dark transitions.
- `ThreeNotesProvider.tsx`: one set of MotionValues shared by content and the director. Scroll does not set React state every frame.
- `ThreeNotesDirector.tsx`: measures the original DOM anchors; updates the score in Motion's read phase and renders after Motion applies the bottle/gallery transforms. ResizeObserver, font readiness and content mutations refresh geometry. Native scroll and anchor seeking are supported in either direction.
- `webgl.ts`: a lazy loaded Three.js renderer, three morphing glass notes, a core, and one reused particle/network field. Studio reflections are generated locally. No HDR, model, font or image is fetched by this renderer. Invisible effects skip their update work. Frames are requested by scroll, loading handoff, layout changes and relevant pointer interaction; the scene has no idle animation loop and pauses when the document is hidden.
- `NoteFrame.tsx`: three SVG strokes build the existing project card borders. The WebGL canvas never contains project imagery or copy.

## Budgets and fallback

Full mode uses 480 particles and caps DPR at 1.6. Compact screens, low core/memory counts and Save-Data use 144 particles, DPR ≤ 1.15 and a cheaper material without transmission. WebGL/context/shader failure falls back to DOM notes without blocking the page. Reduced Motion avoids importing WebGL, disables smoothing, shows static statistics and all memory statements, and uses a project grid. Changing Reduced Motion during the visit reconfigures and disposes the renderer and scroller.

## Verification and preview review

Run `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build`, then `npm run smoke` for an HTTP-only production check. The 24 Node tests include an immutable snapshot of the original content and asset hashes, plus scroll/arrival/quality invariants.
